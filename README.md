## 📝 Notes App

A simple and intuitive Notes Application built using React.js and JavaScript. This app allows users to create, edit, delete, and search notes — perfect for personal to-dos, reminders, and quick thoughts.

## 🚀 Features

📝 Create and save new notes
✏️ Edit existing notes
🗑️ Delete notes
🔍 Real-time search functionality
💾 LocalStorage support (notes persist on refresh)
📱 Responsive and mobile-friendly design

## 🛠️ Tech Stack
**Frontend**: React.js, JavaScript
**Styling**: CSS / Tailwind CSS / Bootstrap (customize as per your setup)
**Storage**: Browser LocalStorage

## ⚙️ Getting Started (Run Locally)

**1. Clone the Repository**
git clone https://github.com/Avneetkau/Note-App
cd notes-app

**3. Install Dependencies**
npm install

**4. Start the Development Server**
npm start
Visit the app at: http://localhost:3000
